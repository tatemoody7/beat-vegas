# Assumptions ledger — every live rule on the money path, and what justifies it

**v1, written 2026-10-06.** One row per rule or constant that decides whether real money
moves, how much, or what it is judged by. Every `file:line` was read in the code on the day
this was written; the parity tests (`tests/test_gate_parity.py`, `tests/test_docs_parity.py`)
keep the values in step between Python and TypeScript, but line numbers drift with edits —
treat them as "where to look", and the symbol name as the anchor.

**Nothing changes from this document.** It records what each rule rests on; it adopts,
tunes or retires nothing. A change to any row lands through its own registered row in
`docs/HYPOTHESES.md` (add the row first) or its own PR, and this ledger is updated after.

## How to read "basis"

| basis | meaning |
|---|---|
| **evidence** | a measured result on data is on file, with its n and interval, and the rule follows from it. The set it was measured on is named; most of it is the 2023-25 real-close set, which the registry marks **spent** for rule selection. |
| **design** | a choice made for a stated reason (bankroll safety, house rules, fail-closed, data quality) with no outcome evidence for the particular value. Tate's call is recorded where it was one. |
| **scope** | the rule marks where validation stops (a regime the backtest never covered), not a prediction about outcomes there. |
| **registered** | the value is frozen inside a pre-registered row and may not move during the test; its justification is the registration, not an outcome. |
| **derived** | arithmetic over other rows; it has no justification of its own. |
| **display** | the number changes wording or colour only; no money gate reads it. Listed so nobody mistakes it for a gate. |

The last column is blank on purpose: it is for Tate's verdict on each row (keep / test /
retire), not for the author's.

## What the table says, in one paragraph

Two rows carry outcome evidence and both come from the spent 2023-25 set: the gap rule
(top 20% by gap) and the cap-5 ranking that sits on top of it. One gate has a **live**
record, the price gate, and that record is loss avoided rather than edge. Everything else
on the money path is design or scope — chosen for a stated reason, never measured against
an alternative value — and the only live instrument that can move any of it is H-STOP-2,
which judges the whole rule at once, not its parts. That is the honest state: the system
measures one rule prospectively and inherits the rest.
